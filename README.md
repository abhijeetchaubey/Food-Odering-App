# 🍔 3AM Food - Food Ordering Web App

Welcome to **3AM Food**, a modern food ordering web application built with React!  
Order your favorite meals, browse restaurants, and enjoy a seamless user experience—anytime, anywhere.

---

## 🚀 Features

- **Modern UI**: Responsive design with Tailwind CSS for a delightful experience on any device.
- **Live Restaurant Listings**: Browse restaurants with real-time data from Swiggy APIs.
- **Search & Filter**: Instantly search and filter restaurants by name or rating.
- **Restaurant Menus**: View detailed menus, offers, and categories for each restaurant.
- **Cart System**: Add, remove, and clear items from your cart using Redux Toolkit.
- **User Authentication (Mock)**: Login/Logout functionality with context-based user state.
- **Online Status Detection**: Get notified if your internet connection drops.
- **Lazy Loading**: Fast initial load with code-splitting for Grocery and Contact pages.
- **Attractive Footer**: Social links, quick navigation, and contact info.
- **Custom Hooks**: Reusable hooks for fetching menus and checking online status.
- **Error Handling**: Friendly error pages for broken routes.
- **Testing Ready**: Jest and React Testing Library setup for robust testing.
